# Mandatory Task Completion Rule: Commit Summary & Description

Whenever a task is done, ALWAYS write a commit summary and commit description fit for the task done so the user can commit to the project's GitHub repository.

Rules:
- Commit summary: ≤50 characters, Conventional Commits format (e.g., `feat: ...`, `fix: ...`, `chore: ...`).
- Commit description: Bullet points specifying changes made, files modified, and rationale.
- Project GitHub Repository: https://github.com/meytiii/dideban_amin
