# /impeccable Workflow

1. Maintain and reference `DESIGN.md` and `.impeccable/design.json`.
2. Apply mode appropriate design (Operate for admin, Persuade for public).

4. Auto-document design tokens, typography, and component specifications into `DESIGN.md`.
