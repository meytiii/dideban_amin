گر نمی‌خواهید تنظیمات ویندوز را تغییر دهید و می‌خواهید دیتابیس مستقیماً با ساعت فعلی ویندوز شما (+04:30) هماهنگ شود، این کوئری را در دیتابیس اجرا کنید:

ALTER DATABASE herasat_db SET timezone TO '+05:30';

سپس با کوئری زیر بررسی کنید:

SELECT NOW(), CURRENT_SETTING('TIMEZONE');

خروجی فوراً ۱ ساعت جلو می‌آید و با ساعت فعلی ۱۰:۲۶ ویندوز شما یکی می‌شود.
